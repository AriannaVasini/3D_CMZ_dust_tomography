# 3D gas reconstruction along lines of sight in the Central Molecular Zone

Code accompanying the paper *A Novel Approach to 3D Dust Mapping of the Central Molecular Zone* (Vasini et al. 2026, [arXiv:2609.10782](https://arxiv.org/abs/2609.10782)).

For each line of sight (los) towards the Galactic Centre, the code reconstructs the gas column density Σ(y) along the los from the positions, velocities v_ℓ and gas columns Σ_obs of the stars of the nuclear stellar disc (NSD), using an MCMC (NumPyro). Two mock gas distributions of the paper can be used:

- **Ring50**: an analytic ring of gas;
- **Fractal** (Fractal3, Fractal2, Fractal1): the same ring plus a gaussian background (σ_R = 1 kpc along the los), multiplied by a 3D fractal field with power spectrum P(k) ∝ k^−α.

The stellar density P(y) and the velocity likelihood P(v_ℓ|y) along each los (computed with AGAMA) are provided in `Input/P_y.pkl` and `Input/P_vl_y.pkl`. All the other inputs (stars, gas profiles) are generated by the code the first time they are needed, and loaded from disk afterwards.

Names follow the paper: y is the coordinate along the los (the Sun is at y = −8.2 kpc), (ℓ, b) the centre of the cell on the sky, both in pc.


## Repository structure

| File | Content |
|---|---|
| `main.py` | Main script. All the user choices are in the **SETTINGS** section at the top |
| `agama_model.py` | AGAMA model of the NSD (Sormani et al. 2022) and stars of a los |
| `gas_profile.py` | Ring50 model, σ_fov of the cell and normalization of the Ring50 to M_CMZ |
| `create_fractal.py` | 3D fractal field, σ_fov of the cell and normalization for the Fractal models |
| `precompute_jax_compatible.py` | Quantities computed once before the MCMC: log P(y), log P(v_ℓ\|y), matrix W of the weights w_i(y), Σ(y), Σ_obs |
| `posterior_jax_compatible.py` | Posterior used by the MCMC (JAX) |
| `plot_results.py` | Plots of the mock and recovered gas profile and cumulative mass, made at the end of every MCMC |
| `requirements.txt` | Python packages and versions |

`Input/` contains `P_y.pkl` and `P_vl_y.pkl`, with P(y) and P(v_ℓ|y) (dictionaries with key (ℓ, b) in pc). The NSD model is symmetric for ℓ → −ℓ and b → −b, so only the quadrant ℓ < 0, b < 0 is stored and the other lines of sight use the symmetric one. All the other files in `Input/` and the folder `Results/` are created by the code.


## Installation

The code needs **Python ≥ 3.11** (it was tested with Python 3.12.5) and a **C++ compiler** (needed to install AGAMA).
On macOS the compiler comes with the Xcode command line tools:

```bash
xcode-select --install
```

**1. Download the code**

```bash
git clone https://github.com/AriannaVasini/3D_CMZ_dust_tomography.git
cd 3D_CMZ_dust_tomography
```

**2. Create and activate an environment** (here with conda; any environment with Python ≥ 3.11 works)

```bash
conda create -n cmz_gas python=3.12
conda activate cmz_gas
```

**3. Install the Python packages**

```bash
pip install -r requirements.txt
```

**4. Install AGAMA**

```bash
pip install setuptools wheel
pip install agama --no-build-isolation --config-settings --build-option=--yes
```

`--build-option=--yes` answers "yes" to the questions of the AGAMA installer (for example, it downloads and compiles the GSL library if it is not found).
This installs the latest version of AGAMA from its repository (https://github.com/GalacticDynamics-Oxford/Agama); the paper used version 1.0.150.

To check that everything is installed:

```bash
python -c "import numpy, scipy, matplotlib, jax, numpyro, arviz, joblib, h5py, h5netcdf, xarray, agama; print('ok')"
```


## Usage

1. Open `main.py` and choose the settings in the **SETTINGS** section (see below).
2. Run it from the folder of the repository:

```bash
python main.py
```

### Settings

| Setting | Meaning |
|---|---|
| `gas_model` | Mock gas distribution: `"Ring50"` or `"Fractal"` (Fractal3, Fractal2 or Fractal1 according to `alpha` in `params_fractal`) |
| `new_profile` | `True` regenerates the gas profile of the los even if its files exist |
| `l_list`, `b_list` | Lines of sight: centre (ℓ, b) of the cells in pc. Cells of 10 pc × 10 pc: ℓ from −185 to +185 pc and b from −65 to +65 pc, in steps of 10 pc. The Galactic Centre is at the corner of four cells; (ℓ, b) = (−5, −5) pc is the los of the paper |
| `y_min`, `y_max` | Extent of the los (pc), at most from −210 to +210 pc (range of the provided P(v_ℓ\|y)) |
| `params` | Parameters of the ring: `rho_0`, `R_R`, `W_R`, `H_R` (kpc) |
| `params_fractal` | Parameters of the fractal: number of points `n_grid_fractal` per side, slope `alpha` of the power spectrum, `seed` |
| `n_stars_pool` | Stars generated with AGAMA in the cell of each los (pool to draw from); at least the largest value of `list_n_stars` |
| `list_n_stars` | Numbers N of stars used in the MCMC |
| `list_res` | Resolutions: width of the bins along the los (pc). Must divide `y_max − y_min` into an integer number M of bins |
| `a_fov` | Scaling factor a of σ_fov in σ_j = √(a² σ_fov² + σ_obs,j²) |
| `M_CMZ` | Mass of the CMZ (M☉) used to normalize the gas density in the plots: for Ring50 the factor is computed as for the figures of the paper (see `compute_norm_ring` in `gas_profile.py`); for the Fractal models it is the mass of (ring + background) × fractal inside the cylinder R ≤ 80 pc (plane of ℓ and y), \|b\| ≤ 50 pc |
| `n_warmup`, `n_samples`, `n_chain`, `target_accept_prob`, `max_tree_depth`, `seed` | MCMC (NumPyro NUTS) |

The code checks the settings before starting and stops with a message if a los, a resolution or the number of stars is not valid.

### What happens the first time

The first run of a los generates its inputs; the following runs load them from `Input/`.

- **AGAMA model of the NSD**: built once per run, only if the stars of some los are missing (a few minutes).
- **Stars** of the los: `n_stars_pool` stars sampled directly from the distribution function of the NSD inside the cell (a few seconds for 10000 stars). The random seed depends on the los, so a los always has the same stars.
- **Fractal**: the 3D field (`n_grid_fractal`³ points) is generated in memory; with `n_grid_fractal = 400` it takes about 1 minute and about 3.5 GB of RAM. The fractal is not saved: with the same `params_fractal` (seed included) it is always the same.
- **σ_fov of the cell** (Ring50 and Fractal): the cell is divided into sub-cells, the gas column is computed in each of them and σ_fov is their standard deviation. A plot of the cell with the gas column of every sub-cell is saved.


## Output

```
Input/
├── P_y.pkl                                         stellar density along the los P(y) of every los, provided
├── P_vl_y.pkl                                      velocity likelihood P(v_l|y) of every los, provided
├── Fractal/rho_scale_Fractal{alpha}.npy             normalization of the Fractal models
└── Input_l{l}_b{b}/                                 e.g. Input_l-5_b-5
    ├── stars_pool_{n_stars_pool}.npy                stars of the cell: y, x, z (kpc), id, v_l (km/s)
    ├── {N}_id_stars.npy, {N}_v_l_stars.npy, {N}_y_stars_kpc.npy, {N}_y_stars_pc.npy
    ├── Ring50/                                      sigma_fov of the cell (and its plot), Sigma_obs of the stars
    └── Fractal{alpha}/                              sigma_fov and mean density of the cell (and its plot), Sigma_obs of the stars

Results/
└── Results_l{l}_b{b}/
    ├── Ring50/                                      mock density rho_mock and Sigma(y) of the mock
    │   └── {N}Stars_{res}pc/                        MCMC samples (mcmc_backend.h5), bins (parameters.npz), summary (summary_array.npy)
    │       └── Plots/                               plots (see below)
    └── Fractal{alpha}/                              same structure
```


At the end of every MCMC two plots are saved in `Plots/` (y in pc):

- `Gas_Profile_{N}Stars_{res}pc.pdf`: mock and recovered (geometric median of the posterior samples) density, M☉ pc⁻³, with the 16-84 percentiles of the posterior;
- `Cumulative_mass_{N}Stars_{res}pc.pdf`: mock and recovered cumulative mass along the los, M☉ pc⁻².

For the Fractal the names start with the value of `alpha` (e.g. `Gas_Profile_3_500Stars_20pc.pdf`). Both plots report the number of stars, the resolution (width of the bins) and the earth mover's distance (EMD) between mock and recovered profile.


## Differences with respect to the paper

The results of the paper are not reproduced exactly, because:

- the stars are sampled directly in the cell of each los instead of being drawn from a single sample of the whole NSD (statistically equivalent, but different stars);
- the fractals are generated with a fixed seed, so they are a different realization.
